Data Modeling Theory Exercise

1. ER Components: Entity: A real-world object, animate or inanimate, that is easily identifiable (e,g Book, Author,Publisher,Customer,Payment)

Relationship: The association among entities (e.g. Customer reviews a book, An Author writes a book, A Publisher publishes a book, Customer makes payment)

Attribute: Properties describing an entity (e.g. Customer ID,Customer name,Publisher ID, Publisher name,Author ID , Author name, Payment ID,Amount, Payment method)

2. Data Model Levels:Conceptual Data Model: Defines what the system contains. Created by business stakeholders and data architects to organize and scope business concepts and rules
primary focus: Show what information the business needs and how different entities are related. It focuses on ter overall structure of the data without technical details

Physical Data Model:Describes how the system will be implemented using a specific DBMS (like PostgreSQL). Created by DBAs and developers for actual database creation. 
Primary focus:Shows how the database will actually be be implemented in a specific database system. It includes technical details such as tables , columns, data types and primary keys
